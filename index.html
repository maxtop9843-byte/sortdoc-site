SortDoc

Sort selected paragraphs or list items in Google Docs, without losing formatting.

What SortDoc does

SortDoc is a Google Docs editor add-on. It sorts the paragraphs or list items you have selected inside a Google Doc, A → Z or Z → A, and keeps each line's own formatting. It does nothing else: no file conversion, no cloud storage, no account of any kind.

Select the lines you want in order, then choose Extensions → SortDoc → Sort A → Z. That is the whole product.

Formatting moves with the line

Most sorting tools read your lines out as plain text, sort the strings and type them back, which is why bold, links, headings and bullets tend to disappear. SortDoc moves the paragraphs themselves, so each line keeps its own formatting: bold, italic, underline, strikethrough, colours, highlights, hyperlinks, fonts, sizes, alignment, indentation, headings, bulleted lists and numbered lists.

It refuses rather than risk your document

If SortDoc cannot sort a selection safely, it changes nothing and says so. Selections spanning two document tabs or two table cells, selections with unselected content in the middle, and lines containing unverified elements are all refused — leaving the document exactly as it was.

Privacy

SortDoc makes no network requests. It has no server, no database and no analytics. Your document content is never transmitted or stored anywhere, and the add-on can only access the single document you open it in.

Limitations

  • Table rows are not sorted (paragraphs inside one cell are)
  • Numbers sort as text, so 10 comes before 9
  • No date sort, last-name sort, or custom rules
