SortDoc — Privacy Policy

Last updated: 15 August 2026

SortDoc is a Google Docs editor add-on that reorders the paragraphs or list items you have selected. This policy describes exactly what it does with your data.

In short: SortDoc does not collect, store, transmit, or share any of your data. Sorting happens inside Google's Apps Script runtime, on the document you are already looking at, and nothing leaves it.

What SortDoc accesses

SortDoc's own code uses exactly two OAuth scopes:

  • https://www.googleapis.com/auth/documents.currentonly — permission to read and modify only the single document the add-on is currently open in. It does not grant access to your Google Drive, to your other documents, or to any file you have not explicitly opened SortDoc in.
  • https://www.googleapis.com/auth/script.container.ui — permission to display the SortDoc menu and its message dialogs inside the Google Docs interface.

When an app is distributed through the Google Workspace Marketplace, Google additionally includes two standard sign-in scopes on every listing — userinfo.email and userinfo.profile — so that the Marketplace can identify who is installing the app. These are added by the Marketplace platform and cannot be removed from a listing. SortDoc's code never reads them: it makes no call to any profile or identity API, and it does not store, log or transmit your name, email address or profile picture.

SortDoc does not request access to Gmail, Google Calendar, Google Contacts, or your Drive file list.

How your document content is used

When you choose Sort A → Z or Sort Z → A, SortDoc reads the text of the paragraphs or list items your selection covers, derives a temporary comparison key from that text in memory, uses it to decide an order, and reorders the blocks in place.

That processing happens entirely within the Google Apps Script execution environment. The text exists only for the duration of that single run and is discarded when it ends.

What SortDoc does not do

  • It does not send your document content, or any part of it, to any external server.
  • It has no backend, no database, and no storage of any kind.
  • It makes no network requests. It does not use UrlFetchApp or any other outbound request mechanism.
  • It does not use AI or machine-learning services, and does not use your content to train any model.
  • It does not collect analytics, telemetry, usage statistics, or crash reports.
  • It does not use cookies or any tracking technology.
  • It does not sell, rent, or share data with third parties, because it holds none.
  • It does not create user accounts and does not ask for your email address.

Error logging

If an unexpected error occurs while reordering, SortDoc writes a message to Google Cloud Logging, which is the standard error-reporting mechanism for Apps Script. These entries are visible only to the developer, are retained under Google's default retention period, and contain the error text only. Your document content is not written to these logs.

Google API Services User Data Policy

SortDoc's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

SortDoc retains no user data, so there is nothing to retain or delete. Uninstalling the add-on removes its access immediately. You can review and revoke access at any time from your Google Account permissions page.

Children's privacy

SortDoc is a general-purpose document utility and is not directed at children. It collects no personal information from anyone, including children.

Changes to this policy

If SortDoc's data handling ever changes, this policy will be updated in the same release as the change, and the "last updated" date above will reflect it. Any change that would introduce data collection would be described here before it ships.
