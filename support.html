SortDoc — Support

Last updated: 15 August 2026

How to use SortDoc

  1. Open a Google Doc.
  2. Select the paragraphs or list items you want to sort. Selecting part of a line is fine — SortDoc sorts the whole blocks your selection touches.
  3. Choose Extensions → SortDoc → Sort A → Z (or Sort Z → A).
SortDoc sorts whole paragraphs or list items, not the words inside a paragraph. It moves each block together with its own formatting.

Sorting rules

RuleBehaviour
CapitalisationIgnored when comparing, so banana and Banana are treated as equal
Leading/trailing spacesIgnored when comparing, and never removed from your document
Accents and non-Latin textCompared using locale-aware ordering
Identical valuesKeep their original relative order, in both directions
Empty paragraphsSort first in A → Z, last in Z → A
NumbersCompared as text, so 10 sorts before 9

Messages you might see

MessageWhat it means
Nothing selectedNo text was selected. Select the paragraphs you want to sort first.
Nothing to sortYour selection covers only one block. Sorting needs at least two.
Unsupported selectionSortDoc cannot sort this selection safely, so it changed nothing. See below.

Why a selection might be refused

SortDoc refuses rather than risk damaging a document. A selection is refused when it:

  • spans more than one part of the document — for example two different table cells, or two document tabs;
  • is not one continuous run of blocks, so something unselected sits in the middle;
  • mixes two different lists;
  • includes a block containing a footnote, page break, equation, inline drawing, or horizontal rule, whose behaviour has not been verified.

When a selection is refused, your document is not modified at all.

Undoing a sort

Press Ctrl+Z (Cmd+Z on Mac). An Apps Script edit may be recorded as more than one undo step, so you may need to press it more than once. Google Docs version history (File → Version history) can also restore an earlier state.

Known limitations

  • Table rows are not sorted. Paragraphs inside a single cell can be sorted.
  • Numbers sort as text; natural number sort is not implemented.
  • Sorting by date, by last name, or by custom rules is not implemented.
  • Behaviour with Google Docs comments or suggestion mode attached to sorted blocks has not been tested.

Privacy

SortDoc collects nothing, stores nothing, and sends nothing anywhere. It can only access the one document you run it in. See the Privacy Policy.
